# Intelligence output templates

Version 2; blank reusable contracts, not research findings. Source: [current playbook](CONTENT_INTELLIGENCE_PLAYBOOK.md). Use NULL with a reason for unavailable values. Keep private analytics and identifiable participants out of the public repository.

- Finding ID / canonical entity ID / type / canonical URL:

- Primary behavioral cohort / secondary fit / cohort-evidence limitations:
- What's new / baseline / current observation / growth calculation / period / denominator:
- Independent creators and platforms / duplicate or syndication checks:
- Evidence items: source, inspected segment, evidence type D/O/I/FP, confidence and limitation:
- Viral opportunity: four component assessments, normalization/rationale, separate total or incomplete:
- Story/IP potential: four component assessments, normalization/rationale, separate total or incomplete:
- Execution opportunity: four component assessments, normalization/rationale, separate total or incomplete:
- Sample size / confidence / missing data (separate from scores):
- Rising, peaking or fading / historical evidence for that label / next freshness review:
- Character or emotional hypothesis / why this might become original Roblox-native content:
- Original application / do-not-transfer elements / rights status / production constraints:
- WATCH / INVESTIGATE / TEST / DEVELOP PILOT / RIGHTS REVIEW recommendation:
- Next action / accountable person / prerequisite / proposed target:

If there is no meaningful new finding, record no material change. Do not recycle the leaderboard as new intelligence.
